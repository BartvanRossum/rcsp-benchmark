# RCSP Benchmark — Railway Crew Scheduling Problem

A benchmark library of synthetic instances for the **Railway Crew Scheduling Problem (RCSP)**, accompanying the paper:

> B.T.C. van Rossum, *Branch-and-Price for Railway Crew Scheduling: Benchmark Instances and Computational Study*.

## Instance Overview

The library contains **75 instances** partitioned into three size groups:

| Group  | Tasks       | Instances |
|--------|-------------|-----------|
| Small  | up to 1,000 | 25        |
| Medium | 1,001–2,000 | 25        |
| Large  | 2,001+      | 25        |

Each instance is named `s{S}_t{T}`, where `S` is the number of large stations and `T` is the number of tasks.

## Problem Description

The RCSP asks for a minimum-cost set of *duties* — sequences of tasks performed by a single crew member in one working day — such that every task is covered at least once.
Each duty must satisfy the following labour rules:
- Start and end at a crew base (depot)
- Total duty length at most 9.5 hours
- Exactly one meal break of at least 30 minutes, with no more than 5.5 hours of continuous work before or after the break

Costs consist of a variable component (1 unit per second of duty time) and a fixed component (equal to 8 hours of variable cost) charged once per duty.

## Generation

Instances are generated by simulating the full railway planning process:
infrastructure network generation, passenger demand, line planning, timetabling, rolling stock scheduling, and crew scheduling input construction.
Details are given in the accompanying paper.
