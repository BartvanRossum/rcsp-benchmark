    How to submit

    1. Click Submit a solution, or Improve next to an instance, and fill in the details.
    2. Continue to GitHub (an account is needed) and drop your solution .txt into the pre-filled form.
    3. The checker runs within minutes. If the solution is feasible and strictly cheaper than the current best, it is added here and credited to you.

    The file format is described in solutions/README.md. Ties keep the earlier record.

    Instances and checker: B.T.C. van Rossum (2026), arXiv:2606.10081.
